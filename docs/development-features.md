# Version 1 candidate scope

The former unreleased DASH/live/TS/crawler work is included in local **1.0.0-rc.1**. Current acceptance and exact artifact details are in [release-acceptance-v1.md](release-acceptance-v1.md). Historical 0.10 reports and [earlier development proof](development-media-proof.json) describe their original narrower artifacts.

| Feature             | Candidate behavior                                                                                                                                                                      | Boundary                                                                                                                                                                                            |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DASH VOD            | Video/audio review, numbered/time templates, finite timelines, SegmentList, direct SIDX, track offsets, up to 128 contiguous periods, verified MP4 export and retained-source recovery. | Unprotected H.264/AAC fMP4, stable representation choices and compatible codec/timescale/fragment defaults. No hierarchical indexes or leading preroll.                                             |
| DASH live           | Bounded availability window, selected separate audio, finite recording/Finish recording, persisted plan and offline finalization after restart.                                         | One active period, template/list addressing, availability depth at most 600 seconds, complete aligned segments. No dynamic period switching or DRM.                                                 |
| HLS live            | Sliding media windows, duration or Finish recording, retained committed parts and offline finish.                                                                                       | Audio included in the rendition. Manager remains open. Maximum requested duration 24 hours, 8,192 parts and 1 MiB plan metadata. Missing sequences or changed overlap identities stop continuation. |
| HLS discontinuities | Preserve samples across declared clock resets and compatible initialization changes, including durable initialization-source verification.                                              | Codec/timescale/fragment defaults must agree; muxed MP4 track-ID changes are refused. New TS periods require a keyframe.                                                                            |
| MPEG-TS             | Split PAT/PMT assembly with CRC/continuity checks, continuous non-keyframe parts after verified context, and completed separate video/audio composition.                                | Supported single program, H.264/AAC with video access-unit delimiters; 16 MiB source per part. Scrambled packets and unsupported codecs remain refused.                                             |
| Crawler             | Bounded same-origin linked-page traversal, robots/nofollow, reviewed file/HTML candidates, stop with retained results, shared traffic controls.                                         | Defaults: depth 2, 20 pages, 500 results, 20 MiB, 250 ms pacing. Hard maxima: depth 5, 100 pages, 500 results, 64 MiB and five minutes. No script execution or complete offline link rewriting.     |
| Download view       | Compact rows and remembered visibility for website/category, size, speed, remaining time and connections.                                                                               | Names, status, errors and actions remain available. Persian UI is excluded.                                                                                                                         |

Runtime media and crawl work uses packaged browser workers. Public URL, redirect, downgrade, website permission and original-source session rules apply to all child resources. XML has structural/expansion limits and rejects DTD/external entities; crawler HTML is inert. Media plans have an aggregate 32,768-source-part / 8 MiB expanded-address bound. Initialization and fragment metadata are capped at 1 MiB; encrypted plaintext/TS parts at 16 MiB. Compound checkpoint admission includes new initialization and key traffic.

Required unlimitedStorage exempts extension storage quota/eviction for large staging files; physical disk limits remain. No native host, remote conversion service or runtime executable download is added. Version-4 URL lists retain selected DASH tracks and recording limits while excluding source snapshots, hashes, completed ranges and browser-session consent.

Current evidence is split between [large-file proof](capacity-v1.json), [comparative benchmark](benchmark-v1-results.md), [media proof](media-proof-v1.json) and [release report](release-acceptance-v1.md). Actual macOS and native permission/picker acceptance remain explicit [manual gates](release-manual-checks.md), not inferred from headless Windows fixtures. Work remains local and uncommitted.
