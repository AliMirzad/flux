# IDM / AB Download Manager capability audit

This is the implementation and acceptance checklist for the requested browser-only parity work. An item is complete only when its behavior is implemented and verified. Desktop-only actions remain explicitly constrained by the original no-helper/no-native-host requirement.

Primary feature references: [IDM features](https://www.internetdownloadmanager.com/features2.html), [AB Download Manager](https://abdownloadmanager.com/), [AB documentation](https://abdownloadmanager.com/docs). Browser constraints: [Chrome Downloads](https://developer.chrome.com/docs/extensions/reference/api/downloads), [MV3 service-worker lifecycle](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle), [File System Access](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access).

| Capability                                                                      | Current state / required work                                                                                                                                                                                                                                                                                                                                                                             |
| ------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Segmented HTTP/HTTPS transfers, adaptive/manual limits                          | Implemented; existing real-server/hash coverage.                                                                                                                                                                                                                                                                                                                                                          |
| Pause, resume, retry, checkpoints, changed-resource validation                  | Implemented; existing recovery/corruption coverage.                                                                                                                                                                                                                                                                                                                                                       |
| Automatic clicked-link capture                                                  | Implemented opt-in for existing tabs and frames; real Chrome capture tests pass. Native permission-consent UI remains a manual gate.                                                                                                                                                                                                                                                                      |
| CDN redirects                                                                   | Fixed the reproduced 0.2.0 cold-background failure; single-origin, missing-CDN-grant and terminated-worker regressions pass in Chrome.                                                                                                                                                                                                                                                                    |
| Global/per-file speed control, priorities, single queue                         | Implemented.                                                                                                                                                                                                                                                                                                                                                                                              |
| Multiple named queues with independent concurrency and schedules                | Implemented concurrency, start/stop, bandwidth, selected weekdays, overnight windows and absolute start/stop dates. Real Chrome starts, pauses and resumes at selected window boundaries with correct output hashes.                                                                                                                                                                                      |
| Batch URL entry, text/JSON import/export, duplicate handling                    | Implemented, including numbered patterns, transactional add, duplicate skipping and review filters. Real batch/queue transfers pass; discovery, selected import and export acceptance pass in Chrome.                                                                                                                                                                                                     |
| Refresh an expired source URL while safely validating checkpoints               | Implemented and verified for expired-link replacement in Chrome. Existing identity checks restart safely when the final resource URL changes.                                                                                                                                                                                                                                                             |
| Download all links on a page, filtering and selected import                     | Implemented bounded page link/direct-media discovery and batch review; selected files transfer correctly in Chrome.                                                                                                                                                                                                                                                                                       |

OS clipboard transport is not separately automated. No continuous clipboard surveillance.                                                                                                                                                                                                                              |
| Category organization, search/sort, details, dark/light themes                  | Implemented.                                                                                                                                                                                                                                                                                                                                                                                              |
| Bulk selected actions                                                           | Implemented selection and pause/resume/cancel/remove; selected resume starts a real correct-hash transfer in Chrome. Confirmed selected cancellation/removal and list export also pass in Chrome.                                                                                                                                                                                                         |
| Direct media detection                                                          | Implemented for ordinary direct resources.                                                                                                                                                                                                                                                                                                                                                                |
| HLS / DASH without DRM                                                          | Implemented in the unreleased working tree for a bounded subset: HLS fMP4/continuous H.264-AAC TS, identity AES-128, separate fMP4/TS audio, finite muxed HLS live recording, compatible declared discontinuities, static multi-period DASH and finite single-period dynamic DASH with selected audio. Codec changes and DRM remain unsupported. See [development verification](development-features.md). |
| Folder destination and automatic save of completed verified files               | Implemented default automatic saving to Chrome's Downloads/category folders, selected-folder handles, serialized verified export, numbered collision handling and optional category subfolders. Downloads and writable-stream paths recheck SHA-256 before destination commit. Real Chrome OPFS destination tests pass through manager reload. Native directory-picker consent is a separate manual gate. |
| Browser-only fallback for session/POST/blob requests                            | Compatible source-session GETs run in Flux; other POST/referrer-bound transfers retain linked Chrome controls. Bounded approved blob/data ingestion stages and hashes page files up to a conservative 1 GiB cap; failure falls back to Chrome. These files cannot be replayed from their source-page URL. See [0.10 review](code-review-0.10.md).                                                         |
| HTTP/proxy authentication and per-app proxy routing                             | No credential scraping or OS proxy changes. Browser network configuration applies. A secure explicit authentication workflow requires separate review.                                                                                                                                                                                                                                                    |
| Site crawler/offline page projects                                              | Bounded same-site traversal, robots/nofollow, file/page candidates, stop with retained results, and batch selection are implemented locally. Complete offline HTML/CSS link rewriting is outside this crawler. See [development verification](development-features.md).                                                                                                                                   |
| Repeating queues, completion notifications/sounds, bandwidth quotas             | Implemented optional local completion tones, once-only queue notifications, periodic copies and a durable shared allowance. Real Chrome tests verify allowance recovery, calendar windows, periodic hashes and audio-graph activation. Native speaker output remains manual.                                                                                                                              |
| Bounded periodic retries for failed queue jobs                                  | Implemented opt-in global/per-queue bounded automatic restarts for typed transient failures, durable counters/deadlines, exponential delays, calendar/concurrency gates and manual stop. Real Chrome retains a completed checkpoint across failure/reload and verifies resumed output. See 0.6 evidence.                                                                                                  |
| Persian/localized UI, configurable columns/compact view                         | Persian UI excluded from this implementation at the user’s request. Compact rows and visibility choices for website/category, transferred size, speed, remaining time and connections are implemented, with local persistence and Reset view. Names, status, integrity errors and actions remain available.                                                                                               |
| FTP/MMS protocols                                                               | Chrome fetch cannot provide these transfer transports; no native helper permitted.                                                                                                                                                                                                                                                                                                                        |
| OS shutdown, launching an antivirus/executable, catch downloads from other apps | Unavailable to this browser-only architecture; no native host or helper will be added.                                                                                                                                                                                                                                                                                                                    |
| Transfer while Chrome is closed, silent arbitrary filesystem access             | Unavailable; manager/browser lifetime and explicit destination permissions apply.                                                                                                                                                                                                                                                                                                                         |
| Auto-update                                                                     | Web Store handles published extension updates; unpacked evaluation requires Reload. No remote executable updater.                                                                                                                                                                                                                                                                                         |

This checklist deliberately preserves remaining feasible work rather than treating a passing compatibility patch as full feature parity.
