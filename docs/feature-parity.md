# IDM / AB Download Manager capability audit

This is the implementation and acceptance checklist for the requested browser-only parity work. An item is complete only when its behavior is implemented and verified. Desktop-only actions remain explicitly constrained by the original no-helper/no-native-host requirement.

Primary feature references: [IDM features](https://www.internetdownloadmanager.com/features2.html), [AB Download Manager](https://abdownloadmanager.com/), [AB documentation](https://abdownloadmanager.com/docs). Browser constraints: [Chrome Downloads](https://developer.chrome.com/docs/extensions/reference/api/downloads), [MV3 service-worker lifecycle](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle), [File System Access](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access).

Native permission-consent UI remains a manual gate.                                                                                                                                                                     |

This checklist deliberately preserves remaining feasible work rather than treating a passing compatibility patch as full feature parity.
