# Prepared Chrome Web Store listing

Package: Flux 1.0.0-rc.1. Draft only; no submission or approval.

## Name

Flux - Download Manager

## Short description

Manage resumable downloads, queues and supported media locally in Chrome. Keep the manager open during transfers.

## Detailed description

Flux organizes downloads in your browser with pause/resume, verified parallel HTTP ranges, named queues, schedules, bandwidth controls, categories and batch link review. Optional website integration handles eligible clicked file links. Unsupported website requests can stay with Chrome's original downloader.

Save verified files to Downloads, a chosen folder or Save as. Review supported unprotected HLS/DASH media, select audio tracks, record a finite live window and export MP4. Crawl a bounded set of linked pages on one site, then choose file candidates before downloading them. Use compact rows and choose which transfer details are visible.

Transfers and history stay in your local Chrome profile. Flux has no account, telemetry service, native helper or remote conversion backend. Website access and automatic capture require your consent. Large staging files use the unlimitedStorage permission; physical disk space is still required for staging and a separate saved copy.

Keep the manager tab open for Flux transfers. Scheduling needs Chrome and an active manager. Server compatibility determines whether parallel ranges help; no fixed speed increase is promised. DRM, arbitrary codecs, POST reconstruction and transfer while Chrome is closed are unsupported.
